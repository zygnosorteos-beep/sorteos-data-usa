# Zygno USA Data Hub

Repositorio de datos históricos y resultados oficiales de loterías de Estados Unidos para la aplicación **Zygno USA**.

## 📊 Sorteos Disponibles
- **Powerball:** `resultados_powerball.json`
- **Texas Cash Five:** `resultados_texas_cash_five.json`

## 🔄 Automatización
Los archivos CSV se procesan automáticamente mediante GitHub Actions y se publican en GitHub Pages en la carpeta `/docs`.
